# BackHome

BackHome is an Android application developed using **Kotlin**, **Jetpack Compose**, and **Firebase** to help users report and search for missing or found persons.

The application provides a simple and user-friendly interface where users can register, log in, submit details of missing or found persons, manage their registered records, and help reunite people with their families.

## Features

- User Authentication using Firebase
- Register and Login
- Add Missing or Found Person Details
- Upload Person Information
- View Registered Persons
- Delete Registered Records
- Modern UI with Jetpack Compose
- Cloud Firestore Integration

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM Architecture
- Firebase Authentication
- Cloud Firestore
- Hilt Dependency Injection
